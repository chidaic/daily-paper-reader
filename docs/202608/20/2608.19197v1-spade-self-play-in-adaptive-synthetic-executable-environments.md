## 摘要
持续自我改进需要不断扩大的自生成、多样化和自适应的目标池。对于语言智能体而言，现有的训练环境池（人工策划、静态合成或冻结验证器）在学习者规模扩展时保持目标分布不变。我们提出了SPADE（自适应合成可执行环境中的自我对弈），一种自我对弈强化学习框架，其中单个大语言模型扮演两个角色：一个环境设计器，编写完整的、长时域的训练环境作为可执行代码，具有OpenAI Gym风格的reset()/step()接口；以及一个推理智能体，学习在这些环境中行动。每个环境都是有状态的、多轮的环境（包含状态转换、奖励函数和验证代码），因此一个接口就覆盖了推理问题和多步智能体工具使用。推理智能体的遗憾通过其在有无特权提示下的奖励差距来估计；在优化这一遗憾信号时，环境设计器学会针对智能体能力边缘的环境进行设计，同时保持其可行性。通过广泛的实验，我们发现了几个对成功至关重要的组件：将环境设计器基于从大型预训练语料库中采样的文档进行锚定，并赋予其累积的环境记忆。扩展到30B参数的模型，SPADE在八个预留的数学、科学、代码和推理基准上平均超过最强固定环境基线+5.3，并将工具使用环境在BFCL-v4多轮上提升+5.7，在ACEBench-Agent上提升+13.9；在游戏环境中，与最强基线的差距随模型规模增大而扩大。通过使环境设计本身成为一个可学习的组件，SPADE向开放式自我改进迈出了具体的一步。

## Abstract
Continuous self-improvement requires an ever-expanding pool of self-generated, diverse, adaptive goals. For language agents, existing training environment pools (hand-curated, statically synthesized, or frozen-verifier) keep the goal distribution fixed as the learner scales. We introduce SPADE (Self-Play in Adaptive Synthetic Executable Environments), a self-play RL framework in which a single LLM plays two roles: an Environment Designer that writes complete, long-horizon training environments as executable code with an OpenAI Gym-style reset()/step() interface, and a Reasoning Agent that learns to act in them. Each is a stateful, multi-turn environment (state transitions, reward functions, and verification code), so one interface spans reasoning problems and multi-step agentic tool use. The Reasoning Agent's regret is estimated using the gap between its reward with and without privileged hints; in optimizing this regret signal the Environment Designer learns to target environments at the edge of the agent's capabilities while keeping them feasible. Through extensive experimentation, we find several components critical to success: grounding the Environment Designer on documents sampled from a large pretraining corpus, and giving it an accumulated environment memory. Scaling to 30B-parameter models, SPADE improves over the strongest fixed-environment baseline by +5.3 on average across eight held-out math, science, code, and reasoning benchmarks, and lifts the tool-use setting by +5.7 on BFCL-v4 multi-turn and +13.9 on ACEBench-Agent; on the games setting, the margin over the strongest baseline grows with model scale. By making environment design itself a learnable component, SPADE takes a concrete step toward open-ended self-improvement.

### 1. 核心问题与整体含义（研究动机与背景）

- **核心痛点**：语言模型的持续改进越来越依赖"训练环境"（带有可验证奖励的交互式任务），但现有环境池存在根本性局限：
  - **人工策划**：规模化受限于人写环境的速率；
  - **静态合成**：生成器固定，环境空间不随学习者成长而扩展，模型很快耗尽信号；
  - **冻结验证器**：无法随学习者能力调整难度；
  - **无基础（ungrounded）自对弈**：受"信息对称性"约束，无法提出超越自身知识的新挑战，且易于放大自身错误。
- **研究目标**：实现环境设计与智能体能力的**共同演化（co-evolution）**，让环境分布始终处在学习者能力前沿附近，从而支撑开放式（open-ended）持续自我改进。
- **整体含义**：SPADE将**环境设计本身变成后训练中的一个可学习组件**，而非固定的外部资源——同一个LLM既编写可执行训练环境，又作为推理智能体学习解决它们。这为"AI从自己的经验中持续学习"提供了一条具体路径。

### 2. 方法论：核心思想、关键技术细节与算法流程

#### 核心思想
- 单个LLM πθ 通过角色切换（role-specific system prompt）扮演两个角色：
  - **环境设计器（Environment Designer, ED）**：编写完整、可执行、长期限（long-horizon）的Python环境（Gym风格 `reset()/step()` 接口），同时为每个环境生成一个**特权提示（privileged hint）**；
  - **推理智能体（Reasoning Agent, RA）**：与环境交互并学习解决任务。
- 两个角色的更新共享同一组模型参数（shared policy），通过GRPO更新。

#### 关键技术细节

1. **代码即环境（Code-as-Environment）**：
   - 每个环境是完整的MDP（状态转移、奖励函数、验证代码都编码在 `step()` 中），一个接口统一了单轮推理任务与多轮智能体工具使用任务；
   - 任何可计算MDP都可以写成Python程序，因此环境空间无界，不受人工参数化约束。

2. **基于提示的遗憾奖励（Hint-based regret reward）**：
   - 环境设计器奖励定义为：
     ```
     rD(e) = r̄A(e | h) − r̄A(e)
     ```
   - `r̄A(e|h)` 为有提示时RA的平均回报；`r̄A(e)` 为无提示时的平均回报；
   - 三种情形：高遗憾（有提示能解、无提示不能解）→ 学习前沿；低遗憾且都成功 → 已掌握；有提示低回报 → 不可解；
   - 这是PAIRED最小化最大遗憾原则的一种轻量实现，无需单独对抗者——提示化RA扮演上界策略；
   - 训练时将遗憾下限设为0（max(0,·)），并与一个"平顶难度锚"（目标胜率带 [0.4, 0.6]，权重0.6）混合（遗憾权重0.4）。

3. **语料库锚定（Corpus grounding）**：
   - 每一轮设计器都从外部预训练语料（游戏设置：DCLM数学10k + MegaScience科学5k 文档；工具使用：Nemotron代码语料15k文档）采样新鲜文档作为条件；
   - 防止"隐形缰绳"——无外部信息源的生成器会模式坍缩到自身偏好。

4. **环境记忆（Environment memory）**：
   - 缓冲区存储过去生成的环境，附带遗憾分值和技能标签；
   - 为设计器提供高遗憾种子（可变化）和太易/太难的反例（可避免），使难度保持在学习者前沿。

5. **联合训练稳定化技术**：
   - 每个角色独立归一化优势（per-role advantage）；
   - 对较少出现的环境设计器轨迹做上采样（upweight）；
   - 环境设计器更新延迟k轮（k=4），用截断重要性采样（truncated importance sampling）修正off-policy偏差；
   - 非对称裁剪范围（ε_low=0.2, ε_high=0.28）。

#### 算法流程（每轮循环）

1. **生成**：采样领域提示 → 环境设计器生成环境 e_b（Python代码）→ 验证（语法+可执行性）→ 生成提示 h_b；
2. **无提示回滚**：RA 在无提示条件下进行 G 次回滚（G=16），获得奖励 rA(y|e)；
3. **提示回滚**：RA 在带有提示条件下进行 G 次回滚，获得 r̄A(e|h)；
4. **奖励与更新**：rD ← 遗憾计算；对这两类奖励分别计算优势，通过GRPO联合更新共享策略。

#### 理论分析（附录B）

- 在理想化假设下（提示可取得最优无提示价值；提示化行为可被无提示策略内化），任何纯纳什均衡（pure Nash equilibrium）都使设计器的遗憾为零，且RA在每个环境上都达到提示无关最优——这正是"设计器被迫瞄准可学习前沿"的理论形式化。

  - 学习率等超参数未对每个变体逐一调优，消融变体的最佳检查点选择在套件均值上，可能存在选择性报告偏差（虽然给出了完整轨迹缓解）；
  - 4B/8B模型的提示遗憾信号长期为负（图12），但训练仍有收益，说明小模型下的信号有效性解释较弱。

### 6. 主要结论与发现

1. **自适应设计>固定池**：30B-A3B上SPADE八基准套件均值58.3，比基座+8.1，比最强固定环境基线（RLVE）+5.3；且该优势在固定环境分布趋饱和后继续保留。
2. **规模越大获益越多**：平均增益从4B +5.2、8B +5.7、到30B-A3B +8.1，而Fixed-env GRPO基本维持在+1.2不变（说明固定环境信号随模型增大迅速饱和，自适应课程始终产生新前沿）。
3. **跨领域可迁移**：游戏环境训练能提升科学推理、代码生成和程序性推理，并保持竞赛数学稳定；工具环境训练在ACEBench-Agent（+13.9）和BFCL v4多轮（+5.7，4B为+10.3）上超过专用数据合成系统。
4. **多样性来自语料库**：有语料锚定时Vendi/n=0.68（接近混合群体上限），无语料时0.04；冻结ED、去掉记忆而保留语料则多样性不降（0.70）——多样性和难度提升解耦（语料负责广度，ED训练负责难度）。
5. **设计器会"学会难化"**：环境公式在前言中的暴露率从25%降至5%；奖励粒度从3.7上升到5.8个等级；无语料时同一迷宫任务连续生成41次。
6. **RA行为策略演化**：从"前置推导"（step 0）→"假设-测试-修正"（step 200）→"先取证后推导"（step 300），且仅在程序性任务中表现为短命令，长推导能力保留。
7. **提示遗憾优于EMA学习潜力**：后者仅达前进益的~70%，两者在~50步后分化。
8. **课程广度重要**：六技能课程（+8.1）明显优于两技能课程（+3.5，套件均值53.7 vs 58.3）。

### 7. 优点与亮点

1. **概念上的突破**：将"环境设计"纳入可学习组件，与RA共同演化，针对学习前沿而非静态难度——这是对现有固定环境池范式的实质性扩展。
2. **代码即环境的统一接口**：Gym风格 `reset()/step()`,一个接口同时覆盖单轮推理和多轮工具使用，使框架天然跨域。
3. **提示遗憾奖励设计的巧妙性**：
   - 无需训练独立对抗者；提示自带"上界策略"；
   - 天然过滤掉不可解环境（有提示也低回报）和已掌握环境（无提示也高回报）；
   - 有理论均衡分析支撑（附录B）。
4. **防崩溃工程完整**：语料锚定防模式坍缩、环境记忆防重复、延迟更新+重要性采样稳定联合训练、奖励下限+平顶锚控制难度。
5. **实验证据充分且多层**：定量（8+3基准）、消融（6+变体）、质量追踪（5信号）、多样性和可执行性验证、语言定性（早期vs后期环境/行为）、跨模型族验证（Qwen3+Nemotron）、跨规模（3个骨干）。
6. **诚实披露局限**：明确指出无形式最优性保证、固定任务评估的局限性、以及复杂度受限于基础模型表达力等。

### 8. 不足与局限

1. **算力信息缺失**：未报告GPU型号、数量、总训练成本，无法评估部署可行性或与SFT等其他方法的性价比比较。
2. **无形式收敛保证**：提示遗憾仅有均衡分析，缺乏对非平稳策略更新下收敛性的严格证明；4B/8B下噪声遗憾信号（长期为负）的适用性未充分解释（论文自己也承认这一观察）。
3. **"可学习前沿"的含义较窄**：奖励信号基于当前策略的瞬时能力差距，未证明能推导出最优课程序或避免局部最优（如过早退化为"设计器专打当前弱点"）。
4. **评估仍是固定任务**：论文用固定benchmark衡量能力增长，而非衡量开放式持续改进本身——局限性被作者明确承认。
5. **外部对比公平性存疑**：表2中与AgentScaler、AWM等对比的培训预算/数据/协议不同；附录已做说明，但"超过专用系统"可归因于实验设置差异。
6. **语料依赖**：环境多样性高度依赖外部语料库采样质量；若语料库退化或领域狭窄，多样性供给会随之受限。
7. **工程复杂度高**：需要大量手工prompt工程、验证管道、两角色切换、延迟更新等协同工作，复现代价高；对教学/科研团队门槛较高。
8. **采样成本**：环境生成+无提示/提示双路回滚，每个环境都要双倍回滚计算量（16次×2条臂），训练成本明显高于纯固定环境训练。
