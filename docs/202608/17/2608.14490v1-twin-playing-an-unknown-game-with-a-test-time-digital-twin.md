## 摘要
我们提出了一个测试时世界模型推理（Twin）系统，其中一个前沿编码代理编写可执行世界模型，以完成诸如ARC-AGI-3游戏之类的持续学习任务。传统方法手工设计此类模型，每个任务一个定制设计。每个游戏隐藏其规则和目标，而我们的系统仅通过模拟和交互来构建它们。该系统对网格游戏的归纳先验足够强大，能够在几乎所有关卡上恢复游戏的真实状态转换和目标。重放验证发生在孪生世界模型中。测试框架强制执行：在程序复现所有先前观察到的游戏转换之前，不会执行任何动作。世界模型预测与实际动作结果之间的每次不匹配都成为一个反例，用于修复世界模型。Twin清除了183个关卡中的179个（97.8%），并且在179个关卡中的158个（88.3%）中比人类更高效。该系统在清除的156个关卡（87.2%）中，在获得任何奖励前推断出目标，并在其余关卡中通过搜索自动发现目标。基准测试以0到100分对完成度和动作效率进行评分，与人类首次游玩每个游戏的表现进行对比。直接运行时，基础模型仅得7.8%；现成的测试框架将其提高到61.1%，而我们的孪生世界模型将同一基础模型提升至93.3%，清除了25个游戏中的23个。构建一个可用的世界模型比预期的更简单，而更困难的问题是推断正确的目标。

## Abstract
We present a Test-time World-model Inference (Twin) system, in which a frontier coding agent writes an executable world model for completing continual learning tasks, such as ARC-AGI-3 games. Traditional approaches hand-engineer such models, one custom design per task. Each game hides its rules and goal, and our system constructs them from simulation and interaction alone. Its inductive prior over grid games is strong enough to recover the true transitions of the game and the goal on nearly all levels. Replay validation happens in a twin world model. The harness enforces that an action is not made until the program reproduces every previous observed game transition. Each mismatch between a world model prediction and the actual action result becomes a counterexample that is used to repair the world model. Twin clears 179 out of 183 levels (97.8%), and does so more efficiently than humans in 158 out of 179 levels (88.3%). The system infers the goal before any reward on 156 of the levels it clears (87.2%), and in the remaining levels automatically discovers the goal by search. The benchmark scores completion and action efficiency, between 0 and 100, against humans playing each game for the first time. Played directly, the base model scores only 7.8%; an off-the-shelf harness increases it to 61.1%, whereas our twin world model increases the same base model to 93.3%, clearing 23 out of 25 games. Building a usable world model is simpler than anticipated, whereas the harder problem is inferring the right goal.

## 2. 方法论

### 核心思想
- 把未知游戏看作一个确定性马尔可夫决策过程 MDP，状态是 64×64 的彩色网格，动作是 4~6 个菜单按钮（包括点击坐标）。
- 智能体维护一个可执行世界模型（Python 程序），包含两个函数：
  - `step(grid, action) -> grid`：模拟动力学。
  - `goal_reached(grid) -> bool`：判断是否达成目标。
- 世界模型起初是“恒等映射”空壳，所有规则都通过与真实环境的交互逐步学习和修复。

### 主要流程（Algorithm 1）
1. **观察**：读取当前帧，追加到交互日志 D（记录 (s, a, s') 三元组）。
2. **验证（Validate）**：重放日志中的所有历史转换，要求世界模型必须**完全复现**每一个已观察的转换。只要有一个不匹配，就阻止任何真实动作执行。
3. **探索（Explore）**：
   - **动力学墙（dynamics wall）**：若验证失败，按错误率、效果多样性、支持度等指标对失败规则排序，交给编码代理修复世界模型。
   - **目标墙（goal wall）**：若动力学已通过验证但找不到目标，则在孪生世界内部做更大范围搜索，并根据“颜色消失/新颜色出现/局部变化/全局变化/追溯前沿”等启发式信号生成候选目标状态。
4. **规划（Plan）**：在验证通过的世界模型内做广度优先搜索（BFS），找到通往目标的最短动作序列。
5. **执行校验（ExecuteChecked）**：将计划中的动作逐个提交给真实环境；若预测与真实结果匹配则继续，若不匹配则作为反例追加到日志中，并重新进入修复循环。
6. **目标发现/更新**：在未获得任何奖励前，把候选状态转化为目标谓词，并通过真实执行来测试；若恰好达到该状态却未过关，则永久排除该候选；若过关，则确认目标谓词。

### 关键公式
- 拟合条件（硬约束）：
  \[
  \phi_{fit}(D, \hat{T}) \iff \forall(s,a,s') \in D: \hat{T}(s,a)=s'
  \]
  即：只有世界模型能重放全部历史转换，才允许提交真实动作。
- 可到达性条件（软约束）：
  \[
  \phi_H^{reach}(s,\hat{T},\hat{R}) \iff \exists k \le H, \exists a_1...a_k, s_0...s_k: s_0=s,\ s_i=\hat{T}(s_{i-1},a_i),\ \hat{R}(s_k)=1
  \]
  即：只需要找到一条“想象中”的路线即可。

## 6. 主要结论与发现

1. **测试时编写的可执行世界模型足以高效游玩未知游戏**。
   - Twin 清除 179/183 关、23/25 个游戏，平均得分 93.3。
   - 在 179 个已清除关卡中，158 个比首次游玩的人类动作更少（88.3%）。
2. **更大的提升来自 harness 而非基础模型**：
   - 同一 GPT-5.6 Sol 的直接游玩得分仅 7.8；使用 off-the-shelf Codex 提升到 61.1；使用 Twin 达到 93.3。
3. **动力学学习相对容易，目标推断才是真正瓶颈**：
   - 世界模型在未见过状态-动作对上的精确预测率为 70.1%（明显高于随机）。
   - 在 87.2%（156/179）的已清除关卡中，Twin 在**第一个奖励出现前**就提出了正确目标假设；其余靠搜索补足。
   - 目标谓词精度低（0.214）说明孪生模型“知道世界如何运转，但不完全知道什么才算赢”。
4. **硬性重放验证是长游戏制胜的关键**：
   - 只有 Twin 能清空 bp35、lf52、sk48 等长多关卡游戏，因为未经验证的模型误差被硬约束阻断，不会跨关卡累积。
5. **构建可用世界模型比想象中简单**：即使是部分可观测（如 bp35 的滚动摄像机）也可通过“每处买一次探测”来补齐地图；真正的困难在于定义并验证目标。

## 7. 优点

- **方法创新性强**：把世界模型变成可阅读、可复现的 Python 代码，而非黑盒神经网络；测试时生成、验证、修复和规划一条龙。
- **硬约束验证机制**：在每次评分动作前强制重放全部历史日志，机制上杜绝未验证动作；这种设计比依赖 prompt 提示更可靠。
- **反例驱动修复**：每次预测失败都被转化为一个精确定位的反例，形成 CEGIS 式闭环；在长游戏中有效防止误差累积。
- **目标发现机制**：在无奖励情况下通过“候选目标谓词 + 一致性检查 + 最便宜测试”完成目标推断，解决了强化学习中经典的稀疏奖励/探索问题。
- **实验诚信度高**：提交前哈希记录预测、审计禁用网络搜索、游戏发布日期在模型训练截止之后，避免数据污染；公开所有 25 个游戏逐步重放和全部代码。
- **分析细致**：不仅报分数，还区分动力学准确率与目标精度，给出空间误差分布、每层动作数、每动作 token 数等大量诊断信息。

## 8. 不足与局限

- **对环境的强假设**：
  - 只处理近似确定性、程序可压缩的动力学；随机/概率性游戏不适合。
  - 只验证已观测转移，未观测状态仍可能出错（如 wa30 重放 99%+ 但未见对预测仅 9.9%）。
  - 只支持“一帧可见”的状态；真正隐藏的、永远不在网格中显现的潜在状态无法处理。
- **搜索与计算成本高**：
  - 每动作平均 224k processed tokens，总 2.6B tokens，推理成本远高于直接学习型智能体。
  - 规划深度固定（8/20k 节点，目标发现 14/30k 节点），更远目标可能找不到。
- **目标推断仍不完善**：
  - 目标谓词精确率仅 0.214，假阳性极高；仍有 2 个游戏（sc25、sp80）因“目标墙”而未完成。
  - 目标启发式信号（颜色变化、局部爆发、大变化等）是视觉层面启发式，无法编码更抽象的时序目标。
- **评估范围有限**：
  - 仅在 ARC-AGI-3 上验证，未进行跨领域迁移测试。
  - 跨系统对比时底层模型不一致，绝对分数对比不严格；未提供多次随机种子重复实验（模型 API 不可复现）。
- **可扩展性疑问**：部分可观测场景（bp35）通过缓存逐渐解决，但状态空间更大或更复杂的 3D 环境可能令这种逐条记忆式方法失效。
