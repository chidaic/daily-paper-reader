## 摘要
视频世界模型根据当前观测和用户动作模拟未来状态。近期系统在长序列上展示了令人印象深刻的视频一致性和动作可控性。然而，公平比较这些交互式模型仍然具有挑战性。在实践中，人类玩家通常通过追求长时目标与世界模型交互来进行评估。例如，用户可能旋转360度以观察环境是否保持一致，或走入水中并检查是否生成逼真的水波纹。为实现同一目标所需的动作序列在不同模型之间可能差异很大，这使得固定动作条件评估不适合跨模型比较。为解决这一问题，我们采用多模态智能体玩家与世界模型交互，以实现指定的长时目标。基于这一范式，我们引入了PlayWorld，一个提供171个场景的基准，每个场景都有指定目标。为全面评估性能，我们从四个核心维度对模型进行评估：几何一致性、交互保真度、视线外演化与洞察演化。此外，我们纳入了视频质量和可控性的基本能力指标。在九个最先进的世界模型上的实验表明，当前模型在长时交互目标上仍不可靠，尤其是在保持空间一致性和持续状态演化方面。代码和数据可在https://github.com/kxding/PlayWorld获取。

## Abstract
Video world models simulate future states conditioned on current observations and user actions. Recent systems have demonstrated impressive video consistency and action controllability over long sequences. However, fairly comparing these interactive models remains challenging. In practice, a human player typically evaluates a world model by pursuing long-horizon objectives through interaction. For example, a user may turn around 360 degrees to see whether the environment remains consistent, or walk into the water and inspect whether realistic water ripples are generated. The action sequence required to achieve the same objective may vary substantially between models, making fixed action-conditioned evaluation unsuitable for cross-model comparison. To address this, we employ multi-modal Agent Players to interact with world models toward specified long-horizon objectives. Building on this paradigm, we introduce PlayWorld, a benchmark providing 171 scenarios, each with a specified objective. To evaluate performance thoroughly, we assess models along four core dimensions: geometry consistency, interaction fidelity, out-of-sight evolution, and insight evolution. In addition, we incorporate basic ability metrics for video quality and controllability. Experiments across nine state-of-the-art world models reveal that current models remain unreliable on long-horizon interactive objectives, particularly in maintaining spatial consistency and persistent state evolution. Code and data are available at https://github.com/kxding/PlayWorld.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：视频世界模型（Video World Models）近年来发展迅速，旨在根据当前观测和用户动作持续生成可交互的虚拟环境，代表系统包括 Genie 3、HappyOyster、Matrix-Game、SANA-WM 等。这些模型的目标不仅是生成高质量视频，更是在空间和时间上保持因果一致的演化。
- **核心痛点**：现有的世界模型评测基准（如 WorldScore、WorldMark、MemoBench、Omni-WorldBench 等）大多采用**预定义动作序列或固定相机轨迹**驱动模型。然而，不同世界模型的**动作粒度和响应动态差异很大**：同样的动作指令（如按三次前进键）在一个模型里可能完成 360° 旋转，在另一个里却只转了 120°。这使得固定轨迹评估的分数**不可跨模型比较**。
- **人类玩家的视角**：人类评估世界模型的方式并非检查动作轨迹是否被严格执行，而是围绕一个**高层次的长期目标**（如“旋转 360°看环境是否一致”“走进水里看水花是否真实”）进行自由交互，并根据观测动态调整操作。
- **研究目标**：论文提出 **PlayWorld**，一个基于**多模态 Agent Player（智能体玩家）**的评估框架——由智能体模拟人类玩家，在统一的长期目标下与世界模型自适应交互，从而在不同模型间实现**公平、一致、可扩展**的长时程评测。

## 2. 方法论：核心思想与技术细节

### 2.1 核心思想：目标驱动 + 闭环自适应

- 每个评测案例由三要素构成：**初始世界图像**、**场景相关的长期目标（Long-Horizon Objective）**、**人工标注的基本动作序列（Basic Action Sequence）**。
- 基本动作序列是共享的初始参照，但**并非固定执行**，而是由 Agent Player 根据实时观测动态调整。

### 2.2 Agent Player 设计

- **组成**：Agent Player 由一个可替换的多模态大模型（默认 Claude Haiku 4.5，备选 Claude Sonnet、Gemini 3.1 Pro）和一套 Agent 接口构成。
- **决策空间**：在每个交互步骤，智能体观察生成帧、已执行动作历史、场景描述和目标，从五种决策中选择：
  - **Keep**：继续当前动作或按计划推进
  - **Stop**：当视觉状态已达到目标时提前终止当前动作
  - **Extend**：当移动不足时延长当前动作的持续时长
  - **Correct**：当观测状态偏离参照时，修正或跳过下一个计划动作
  - **End**：当确认目标及所需观测已完成时终止案例
- **闭环流程**：Agent 接口将动作转换为各模型原生控制格式（W/A/S/D、方向键、WAIT），执行动作→捕获生成帧→返回给智能体→智能体决策→继续执行，直至 End 或达到 40 步交互预算。对网页端模型（Genie 3、HappyOyster 等），通过浏览器自动化调度控制并采集帧。

### 2.3 VQA Rubric Verifier 四维评估体系

- **验证器**：Gemini 3.1 Pro 回答每个案例特有的二元（Yes/No）rubric 问题，结合权重（常规问题权重 1，核心定义问题权重 2，N/A 问题权重 0）聚合为 1–5 分。
- **四个评估维度**：

| 维度 | 核心考察内容 | 验证门槛 |
|------|-------------|---------|
| 几何一致性 | 长时程相机运动与回访中的结构保持（场景身份、空间布局、地标唯一性） | Trajectory Validity（路径有效） |
| 交互保真度 | 受控主体对动作的响应、接触/碰撞判定、运动学合理性、视觉反馈（如水花、脚步接地） | Subject and Reachability（主体可到达交互区域） |
| 视线外演化 | 目标离开视野后是否保持同一性并持续合理演化（如削苹果、乘扶梯、墨水扩散） | Trajectory Validity（出视野并回访） |
| 洞察演化 | 静止观察下可见过程的持续展开（如排队结账、容器注满）与场景一致性 | 无需验证（静态观察） |

- 未通过验证门槛的 rollout，该维度分数直接设为最低分 1 分。

### 2.4 基本能力评估

- **视频质量指标**（7 项）：Aesthetic Quality、Imaging Quality、Motion Smoothness、Temporal Flickering（来自 VBench）、Temporal Consistency（来自 Omni-WorldBench）、Depth Stability（来自 MemoBench）、Subject Consistency（来自 HyDRA）。
- **动作可控性指标**（2 项）：Translation Pass Rate 与 Rotation Pass Rate，基于 VGGT 估计相机姿态，与执行动作定义的目标轨迹比较，误差低于阈值（平移 <0.3、旋转 <45°）即通过。
- **Basic Ability Score**：将九个指标的排名均值转换为百分比。

## 6. 主要结论与发现

1. **持续状态演化是世界模型的主要瓶颈**：所有模型在视线外演化和洞察演化维度得分最低。Genie 3 在几何一致性（2.74）、交互保真度（2.40）、视线外演化（1.81）和总分（2.12）上均排第一；HappyOyster 总分第二（1.92）；LingBot-World2 在洞察演化维度领先（1.95）。但整体分数（1.14–2.12）较低，说明没有任何模型达到可靠水平。
2. **长时回访暴露全局空间不一致**：相机环绕地标（如泰姬陵）时，模型可能在多个视角重复生成同一地标的多个不一致副本，破坏了空间唯一性。这说明模型依赖局部外观连续性，缺乏可持续的全局 3D 表示。
3. **交互保真度仅限简单碰撞响应**：第三方视角能较好地在障碍物边界停下角色，但第一人称视角可能穿墙；走入水中等复杂交互难以产生合理的波纹等物理反馈。
4. **轨迹控制能力与世界模型能力可能背离**：SANA-WM 的轨迹验证通过率较高（80.4%），但 rubric 分数低（1.48），说明能控制轨迹≠能维持长期一致性或物理合理性。
5. **自动高质量指标不足以评测交互模型**：绝大多数模型在视频质量指标上表现良好，但动作可控性差、目标完成度低。HappyOyster 获得最高的 Basic Ability Score（76.4%），但这与其世界模型能力排名（第二）不完全对应，说明基础指标误差范围大。
6. **VQA 指标与人类偏好高度对齐**：整体 Spearman 相关系数 ρ = 0.933，各维度分别为几何一致性 0.983、交互保真度 0.933、视线外演化 0.812、洞察演化 0.745，均显著正相关。

## 7. 优点

- **方法论创新**：首次将“目标驱动 + 闭环自适应”的人类玩家评估范式引入世界模型评测，解决了固定轨迹评估跨模型不可比的根本问题。
- **决策设计简洁高效**：Keep/Stop/Extend/Correct/End 五类决策覆盖了交互所需的所有调整类型，同时保持决策空间足够小以降低智能体推理延迟。
- **轨迹验证门槛**：引入维度特定的验证标准，确保只有真正执行了目标轨迹的 rollout 才参与评分，避免“未测试该能力但得分”的虚假评估。
- **完善的评测维度设计**：四个维度互补，分别覆盖空间一致性、物理交互、记忆/隐藏状态演化、长时间可见过程演化，较完整地刻画了世界模型的能力边界。
- **人类对齐验证**：用 600 个人类成对判断验证了自动指标的可靠性，实验设计（双盲、随机顺序、多数一致性、Fleiss' κ）较严谨。
- **跨闭源/开源模型统一评测**：通过 Agent 接口同时支持网页端闭源模型和本地开源模型，大幅扩展了评测覆盖范围。

- **动作先验构建成本高**：171 个案例的“基本动作序列”依赖人工标注，且不同模型的“步长”语义差异大，Agent 需大量在线校准，这限制了评测框架扩展到更大规模场景时的效率。
- **无跨数据集对比**：论文未与 WorldScore、WorldMark 等现有基准在同一批模型上做横向对比，因此难以精确说明 PlayWorld 相对旧基准在“区分度”和“跨模型公平性”上的量化优势。

## 9. 潜在风险与后续研究方向

- **智能体稳定性风险**：Agent Player 的决策质量直接决定评测有效性；若出现多步错误决策（如过早 End、错误 Correct），可能使模型在未充分展示能力时即被终止，产生假阴性结果。论文虽通过消融对比了不同智能体，但未报告智能体自身决策错误的频率或对最终分数的误差传播分析。
- **世界模型的版本漂移**：闭源模型常经在线更新，同一模型在不同评测时间的表现可能变化。论文未讨论时间维度上的评测可重复性，也未给出每次评估对应的模型版本快照策略。
- **未来方向**：
  - 扩大案例规模到千级，并增加更长时程（5 分钟以上）的交互任务；
  - 将轨迹验证从二元判定扩展为连续覆盖度指标（如完成比例、偏离面积）；
  - 引入多验证器投票机制，降低单一验证模型带来的偏差；
  - 探索将 PlayWorld 用于训练阶段的实时反馈（如作为世界模型的奖励信号），而不只是后验评测。

## 10. 总体评价与学术定位

PlayWorld 在方法论上具有鲜明的创新性和实用性，是该领域首个将“人类玩家式目标驱动交互”系统化、框架化的工作。它敏锐地指出了当前评测基准在跨模型不可比性上的根本缺陷，并以“闭环自适应智能体 + 统一目标 + 四维验证”给出了有说服力的解决方案。实验设计相对严谨，消融与人类对齐验证支撑了结论的可信度。不过，其依赖闭源模型、样本规模有限、算力成本未披露等不足也限制了其可复现性与规模化推广。总体来看，论文达到了顶会/顶刊的水准，对世界模型评测的规范化有重要推动意义，但其框架未来仍需在开源化、轻量化与更大规模验证上继续演进。

## 结论

PlayWorld 构建了一套以人类玩家行为为模板的世界模型评测新范式，通过目标驱动的自适应 Agent Player 和四个互补的证据维度（几何一致性、交互保真度、视线外演化、洞察演化），在统一标准下评估了九个代表性世界模型。核心发现是：当前模型在持续状态演化上明显薄弱，且在长时程回访中普遍缺乏全局空间一致性。该工作不仅为世界模型提供了更公平的横向比较手段，也为未来模型训练指明了关键短板所在。
