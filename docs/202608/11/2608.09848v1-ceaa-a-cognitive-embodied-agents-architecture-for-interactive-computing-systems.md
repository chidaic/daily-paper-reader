## 摘要
即使在当今技术进步的背景下，在实时交互式虚拟环境中开发具有认知能力的具身智能虚拟体（IVA）仍然是一个挑战。现有架构通常要么专注于受商业游戏引擎约束的低层反应式控制系统的实现，要么侧重于难以在虚拟世界中实现的推理模型的高层表示。本文基于这一概念，提出了一种用于部署具身IVA的模块化认知架构。该架构建立在已有的、预先建立的框架之上，如“感知-思考-行动”范式和“信念-期望-意图”认知模型等，旨在提供一个可复用的、面向实现的框架，作为在交互式3D计算系统中部署IVA“大脑”的模板。所提出的架构通过提供一个模块化的、面向实现的框架来部署具身的、具有认知能力的IVA，弥合了高层智能体推理模型与实时具身执行之间的差距，从而在复杂的交互式虚拟环境中实现可扩展、自适应和可解释的智能体。

## Abstract
The development of embodied Intelligent Virtual Agents (IVAs) that have cognitive capabilities in real-time interactive virtual environments remains a challenge, even with today's advancements in technology. Existing architectures are often focused on either the implementation of low-level reactive control systems that are constrained by commercial game engines, or high-level representations of reasoning models that can be difficult to implement in virtual worlds. This paper builds on that notion and proposes a modular cognitive architecture for deploying embodied IVAs. This architecture builds on existing, pre-established frameworks such as the Sense-Think-Act paradigm and the Belief-Desire-Intention cognitive model, among others, and aims to provide a reusable implementation-oriented framework as a template for deploying IVA "brains" in interactive 3D computing systems. The proposed architecture contributes by providing a modular, implementation-oriented framework for the deployment of embodied, cognitive-capable IVAs and bridges the gap between high-level agent reasoning models with real-time embodied execution, for scalable, adaptive, and explainable agents in complex interactive virtual environments.

### 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：在实时交互式虚拟环境中部署具有认知能力的具身智能虚拟体（IVA）仍然是技术挑战。现有解决方案存在明显割裂：
  - **低层反应式方法**（状态机、行为树、规则系统）依赖商业游戏引擎（Unity/Unreal），虽能控制实时行为，但缺乏目标导向推理、适应性和可解释性；
  - **高层认知架构**（BDI、SOAR、ACT-R）理论丰富，但由于复杂度高，难以集成到实时3D环境中实际部署。
- **研究动机**：作者在探索VR教学代理的更广泛研究中，发现缺乏一种**实现导向的、可复用的认知架构**，能够同时满足高层推理能力和实时具身执行的需求。
- **整体含义**：论文提出CEAA（Cognitive Embodied Agent Architecture），旨在弥合高层智能体推理模型与实时具身执行之间的鸿沟，为交互式3D系统中的IVA“大脑”提供模块化、可复用的部署模板。

### 2. 方法论：核心思想、关键技术细节

- **核心思想**：CEAA不提出新的推理模型，而是将已有成熟框架（Sense-Think-Act范式、BDI模型、黑板架构、Pandemonium算法）融合为一个连贯的、具有明确组件划分的模块化架构。
- **三层架构**：
  - **用户与环境层**：包含用户、代理和环境中的虚拟物体，不进行认知处理，只提供刺激和事件。
  - **知识层**：通过共享黑板模型维护环境状态和事件日志，作为代理之间的共享知识中枢。
  - **代理层**：负责任何推理、决策和行动，是代理“大脑”的核心。
- **十二个组件及其分工**：
  - **Environment**：通过事件发布-订阅、条件判断或网格规划等方法捕获环境事件，转化为结构化信息。
  - **Knowledge Base**：基于黑板架构范式，集中记录环境事件与状态，供多个代理按需贡献和读取信息。
  - **Sense**：实现选择性感知，基于角色、信念、目标等过滤条件判断事件相关性，防止信息过载。
  - **Memory + Memory Processor**：存储与整理代理的过往经验（情景记忆）和语义知识（事实、用户模型），支持基于相似度匹配、上下文匹配和案例推理的检索。
  - **Think**：作为认知协调器，不实现具体算法，而是编排信息流——整合记忆、信念、期望、意图，驱动推理和规划过程。
  - **Cognitive Construct**：包含三个数据库式子组件——信念（Beliefs，对世界的当前理解）、期望（Desires，目标与动机）、意图（Intentions，已承诺的活跃目标）。
  - **Reasoner**：基于信念评估和更新期望，通过优先级/效用比较选择意图，并处理意图修订。
  - **Planner**：将意图转化为有序或部分有序的抽象动作序列。
  - **Behavior Mapper**：将抽象动作映射为具体可执行的代理行为（动画、对话、手势等）。
  - **Agent Capabilities**：定义代理可在环境中执行的具体能力集合（身体动作、表情、语音等）。
  - **Act**：最终执行行为的接口，负责触发动画、语音、导航等，需满足实时性约束。
- **技术流程（文字描述）**：代理通过Sense感知黑板上的相关事件 → 查询Memory检索类似过往经验 → Think组件整合信息 → Reasoner评估信念/期望并选择承诺的意图 → Planner生成行动计划 → Behavior Mapper将抽象动作映射为具体行为 → Act在环境中执行，同时行为结果反馈回环境，更新知识库，构成闭环。

### 3. 实验设计

- **应用场景**：在Unity3D中构建了两个完全相同的虚拟博物馆环境（一个桌面版、一个VR版），主题为ENIAC和早期计算机历史，内含可交互的ENIAC三维模型和**四个具身教学代理**，分别承担导航员、讲解员、教学助理和评估员角色。
- **参与人数与分组**：92名本科生参与混合方法比较研究，随机分配到桌面组（46人）和VR组（46人）。
- **测试流程**：知识前测 → 与学习环境交互约45分钟 → 知识后测 → 技术接受度问卷（涵盖努力期望、绩效期望、行为意图和态度四个维度）。
- **定性数据**：12名VR参与者参与了结构化焦点小组讨论。
- **互动机制**：代理依据学习者行为（如演示进度、测验回答）动态调整后续动作——例如，完成某个演示后由助理代理跟进，再由评估代理发起测验；记忆机制使代理能识别“已讲解过”的演示并自适应调整回应。
- **对比方法**：本研究是CEAA架构的可行性验证，**没有**与BDI、SOAR等其他认知架构进行直接的对比实验；主要对比的是桌面端和VR端两种部署效果。

### 6. 主要结论与发现

- CEAA能够作为实现导向的架构模板，在实际的交互式3D/VR环境中成功部署具备认知能力、目标导向、自适应行为的多个具身代理。
- 三层十二组件的模块化设计兼顾了高层推理（BDI认知）与实时执行（环境交互、动画、导航），并支持代理间的共享知识协调。
- 验证实验证明该架构支撑的教学代理系统在桌面和VR两种形态下均能有效促进学习，且用户接受度良好。
- 架构本身不替代已有框架，而是将它们组织成一个连贯的流水线，使认知与具身在决策过程中获得同等重视。

### 7. 优点

- **实现导向**：提供从环境感知到行为执行的完整模块划分，降低了将认知架构落地到游戏引擎的转化成本。
- **融合成熟理论**：不孤立创新，而是将BDI、黑板架构、Sense-Think-Act等经过广泛验证的框架有机整合，理论根基扎实。

- **可扩展性与复用性**：模块化设计契合面向对象和组件式开发范式，适配Unity和Unreal等主流引擎，具备跨领域复用潜力。
- **支持可解释性**：认知结构（信念、期望、意图）的显式建模使代理行为具备可追溯的逻辑基础。
